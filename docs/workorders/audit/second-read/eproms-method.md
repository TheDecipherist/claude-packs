## Top five for an unattended build

1. Row 1: refuse to build a unit for a machine whose table or topology is not decoded; tier the queue before any agent starts.
2. Row 2 with 3 and 4: turn the heard reverb faults into measured gates, so no ear is needed.
3. Row 5: search a converted WAV back into the native voice file to fix the layout in minutes.
4. Row 7: descramble and verify the permutation before diffing, and check each dump's vectors land inside a ROM.
5. Row 14: a guard must pass the read-only commands that verify its own rule, or it blocks its own proof.
