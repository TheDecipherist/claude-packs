## Top five

1. #1 Sysex bulk dumps are usually the user area, so a "factory bank" decoded from one is the owner's data.
2. #2 Scale is per parameter, not per unit; settle each by a published range against the stored range at both ends.
3. #6 and #7 Corroborate attributions and enum order against preset names, since printed order is not always encoded order.
4. #3 One byte carries many names; identify by signature and never by counting down an editor's list.
5. #8 Search table addresses as operands, and check a "pointer table" for a constant step before trusting it.
