## Top five

1. Re-anchor policy (find 1): free-run the clock, anchor modulators per block, re-anchor to the host only on a jump over a quarter beat. A frozen host position silently freezes every LFO while the delay stays perfect.
2. Tempo ordering (find 2): resolve the tempo before the block's parameter pull and hand it to each time node as an argument; otherwise delays follow one block late.
3. Program load and the clock (find 3): decide whether a load moves the tempo, and never under an external master.
4. Withdrawn finding, liked sound (find 6): keep it, label it ours, offer both side by side in one flat list.
5. Short times stay off the grid (find 5): never extend divisions downward to reach a timbre-length time.
