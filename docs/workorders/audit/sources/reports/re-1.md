## 4. Top gaps (for an unattended build of a synth from its firmware and its photos)

1. Row 49, find the timer and the control rate: every stored time value is meaningless without the tick, and a wrong divisor scaled every envelope by 16 on one machine.
2. Row 9 and 47, identify the CPU from the image (vector shape, boot idiom, vendor-name trap, MAME driver, which files are code): a wrong decoder prints plausible fiction, and the kit's `re-toolchain` begins after this step.
3. Row 48, disassemble only from a proven entry point and count encodings when there is none: a linear dump from a guessed address gave a whole wrong waveform dispatch.
4. Row 10 and 11, triage and hash every dump before decoding: four "good" archive dumps had a stuck address line and one folder held no unique good bytes.
5. Row 28 to 31, the firmware pass proper: enumerate coefficient senders, find indexed tables by the stride-multiply idiom, trace the restore path, find the shared helpers and the fixed-point convention (one pass gave 160 of 270 bytes a DSP slot).
6. Row 24 and 25, profile the bank byte by byte and derive record size by autocorrelation, before any disassembly of the record.
7. Row 35, find the base of a banked or relocated image by the five scoring tests; a base that is right over half a device is not verified.
8. Row 32 and 77, find the host-bootstrapped DSP program and the download path; the kit has nothing for host+DSP machines beyond the circuit skills.
9. Row 75, the three-tier "is the evidence enough to build" test, so an unattended run creates nothing for a machine it cannot model instead of a unit that looks finished.
10. Row 50, the anchor trick for a black-box chip's absolute scale, and row 36 and 37, the manual pass with "a stated limit is an array size": between them they turn `[EAR]` debts into `[FW]` laws without hardware.
