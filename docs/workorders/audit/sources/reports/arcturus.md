## 3. Top gaps

Ranked for an unattended build of a synth from its firmware and its photos.

1. **How to attribute record bytes from firmware (D5, D6, D7, D8, A29).** The kit has rules about what counts as evidence but no recipe: find the coefficient builders that read the record through a base register, pair each read with the slot-sender call, find the CC/NRPN displacement table (256 entries, 0xFFFF = indirect), walk a runtime-registered option-NRPN dispatch, and know which of the four representations a base register holds. New skill `attribute-the-record` plus a scanner tool. This is the single largest hole; arcturus's whole map came from it.
2. **Read the DSP program, not only the host code (D18, D19, D21).** Calibrate the word convention on slots known elsewhere (slot = er1 / 2^31, a fractional mac does not double), identify allpass versus comb by the feedback sign, and tag a law provisional until the consumer is read (the LFO speed law is a square that only the DSP shows). New skill `read-a-dsp-program`.
3. **Manual tables must be diffed against a second rendering (D26, A28).** `base/skills/pdf-to-md` says "Use docling, not pdftotext" and never mentions that docling's split output shifted cells in exactly the NRPN rows and produced a plausible wrong answer; `pdftotext -layout` was clean. Add a second-render diff for CC, NRPN and value tables.
4. **Version of each manual and image (D23, A27).** A manual feature the firmware lacks is a version mismatch first; record OS and model of every manual and image and read the matching manual. Without it an unattended run "fixes" a correct trace.
5. **Reset turns every switch OFF and a census gate lists each reset value (A3, B7).** A default-ON switch coloured 2,288 programs on one machine and 18 switches defaulted on in another; `neutral-is-exact` covers only blank programs.
6. **Envelope and LFO engine reference (B31, B32, B34, B35, B36).** A firmware build reads stage tables, curve ids and boundary sources from the ROM; with no checklist an unattended run invents semantics nobody will hear. New reference files beside `design-a-preset`.
7. **Frozen IDs also freeze the range, and never put two controls over one byte (D37, A26).** Widening 0-6 to 0-15 re-reads stored normalised automation silently. Extend `parameter-ids-never-change`.
8. **Byte census tool and a per-byte reach count (D4, A22).** A tool that writes the per-offset profile (const / enum / bipolar / unipolar) and vetoes a decode that disagrees; and a perturbation run whose deaf-byte count is a progress number that must fall.
9. **Spread probe in full (D31).** Determinism first, five numbered sections, notes at C2 C4 C6, committed floors and a collapse self-test; the kit skill is five lines.
10. **Measurement method: a changed detector needs both-faults gating, an unmoved offender means a wrong measure, test every velocity layer (B15, B16, B18, B19, B20).** These are the failures green gates miss; none is in the kit.

Honourable mentions: the panel control detector by shape with an overlay proof and a locked layout (A36; the skill exists only as a global on this Mac); NRPN and packed-NRPN decode (D42; the word NRPN does not appear in the kit at all); a generated, currency-gated signal-path audit that walks every patch (A8); verify a handoff's claims on disk (B47); `[DS]` and `[PHOTO]` tags and the split of an analogue machine into firmware and circuit halves (B45, B46).
