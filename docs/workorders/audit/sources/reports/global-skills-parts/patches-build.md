## 4. Verdicts

- build-a-unit: PARTLY IN THE KIT. The standing brief, laws-first, panel-from-photo, never-invent, dead-binding and decay-measurement lessons are in rebuild.md, plugin.md, gates-from-commit-one, prove-control, hit-the-painted-control and every-law-has-a-source. Missing: the skeleton generator itself (kit says it ships none), the Enough / Partial / Not-ready readiness gate before a project is created, the bank-names-equal-the-firmware-table gate, the clock-answer-even-when-no item, and the finish audit tool. Safe to disable once those five are added; it is disable-model-invocation already and references eproms/synthkit paths that other users lack.
