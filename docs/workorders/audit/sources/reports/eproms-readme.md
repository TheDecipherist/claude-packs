## Share: method vs index

- Index and inventory: about 98%. Lines 203-20760 are archive lists, file sizes, photo-source notes ("Reverb listing photo", "vintagesynth.com") and one grade line per model.
- Method: about 2%. It sits in lines 1-200 (grade ladder, CPU table, sorting and sourcing choices) and in about 10 of 830 long RE lines and about 12 long Notes.
- Method-bearing Notes are the analog and no-firmware entries (Electrix, Metasonix, Schippmann, Sherman, TC 1140/2240/1280) and the TC Reverb 4000 and TC 2290 entries. These say what is learned about a machine class, and how to record "no firmware exists".
- The `re-notes.md` pointer appears on 54 models but its text is not here. The how-it-was-done material lives in `reverse-engineer.md`, `sysex.md`, `PIPELINE.md`, `how-we-reverse-engineered-the-supersaw.md` and `tools/` in the same folder. Other slices must cover those.

## Top gaps

1. Identify the CPU from the image, not the vendor name or part number (rows 2, 3, 4): signature table, confidence level, "plausible nonsense" warning, three-sign proof. Lives only in the global `firmware-recon` skill and this README.
2. Byte-swapped images (row 5): 16 H8/300H dumps here; the wrong order gives garbage with no error. Not in the kit.
3. Grade the machine A to F before planning (row 1): the grade picks the method and the proof route. Not in the kit.
4. Full-method order for an A machine (row 7): sysex length table, then corpus profile, then controller-to-offset table, then coefficient builders. Only half-covered by `names-first` and `bank-census`.
5. CPU to disassembler table with exact flags (row 6) in the library toolchain README, so a run never guesses `unidasm -arch`.
6. Packed-sysex OS updates and other OS delivery forms (row 18): unpack before the CPU guess; check `unwrap.mts` covers it.
7. No-firmware machines (row 11): record the evidence and plan no RE step.
8. Where a factory bank hides when it is not sysex (row 17): ROM reset, tape WAV, floppy image, editor format.
9. Check the scan PDF before concluding a MIDI chart is absent (row 9), and keep the page-image PDF beside every OCR'd manual (row 10).
10. Shared-OS and rebadge handling (rows 12, 13): prove shared parts once and name the stand-in manual.

Note for the reader: rows 1-5 and 7 are real method that lives only in the global `firmware-recon` skill and in this README; other users of the kit will not get them. The kit's `re-toolchain` assumes the CPU is already known.
