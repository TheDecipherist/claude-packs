# Review 2: d-10 and W8 with Go in mind

Read-only review, 2026-11-11, of `docs/workorders/typescript/workorder.md` (d-9, d-10, W8, with W2 to W5 for what W8 depends on),
the runtime-cost survey, base-hooks survey section 6, and the code named per row. Claude Code's contract is from
https://code.claude.com/docs/en/hooks.md (fetched today; cited as [hooks.md]). Probes ran in the session's scratchpad `proxy/`
(`probe-daemon.mjs`, `probe-two.mjs`, `probe-workers.mjs`, `probe-worker-body.mjs`) against sockets under `/tmp/claude-502/pb/`;
every daemon started was stopped. Severity: **B** breaks every call (or every call of a session), **S** breaks some calls or some
machines, **U** a surprise (wrong number, confusing message, cost). Order changes name the step and give the clause to add.

## 9. The five changes to make

1. d-10: per project folder, shared by every session (not "per checkout and session"); no stop at SessionEnd; 15-minute idle exit
   counted on hook events only; the socket named by a hash of uid, project, lock hash and node path in a mode-700 cache folder.

   of W8.1 on the event and starts the daemon behind it; a lock file and a ready pipe make one daemon per key; fail open only when
   node cannot start, in a `systemMessage`.

   for byte; hooks get the client's env, cwd and session pid through `ctx`, never the daemon's (agents-held, own-processes, time-guard,
   the 11 import-time `ROOT`s).

   30 ms after the first and sorted by table order; the index queried in the main thread; state files and timing lines written by the
