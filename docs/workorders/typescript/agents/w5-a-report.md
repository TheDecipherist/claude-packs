## Possible module bugs (not fixed; the failing assertion left out of the files)

1. `packs/base/hooks/lib/function-shapes.mts`, `functionsOf`: block-bodied arrow functions are never found.
   `functionsOf('const f = (x) => {\n  return x;\n};', '.js')` returns `[]` (also async, `const h = function (x) {}`,
   and `const k = (x): number => {}`). Cause: `headOf`'s `close` regex does not allow `=>` between `)` and `{`, so the
   arrow-name branch below it is unreachable. The regex is the same at 18f4be6, so not a W4 regression.
2. `packs/base/hooks/lib/repo-index.mts`, `GENERATED` regex `/\b(?:auto-?generated|generated by|do not edit|@generated)\b/i`:
   the leading `\b` can never match before `@`, so a `// @generated` header is not recognised.
   `shapesOfText('// @generated\nfunction f() { return 1; }\n', 'a.ts')` returns a def for `f`; it should return
   `{ shapes: [], st: [], defs: [] }`.
