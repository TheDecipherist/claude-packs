# History

The release history is `CHANGELOG.md`, one entry per version, with the upgrade notes. The notes that lived here (0.9.12 to 0.25.0) were
written as they happened and had fallen behind the code: they describe files and packs that have moved. How things are now is in
`README.md`, `CLAUDE.md` and the code. The old text is in git: `git log --follow -p docs/history.md`.
