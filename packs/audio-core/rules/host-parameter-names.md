# A parameter is named for the host as its design names it

The host shows these names in its automation list; a user finds a parameter by them.

<constraints>
Always do:
- On a rebuild, name each parameter as the machine's own display does (its edit-page strings).
- On our own design, name it `Column . Section . Name`.

Never do:
- Mix the two forms in one unit.
</constraints>
