# The icons of a plugin panel use standard metaphors, one stroke weight, dim at rest

The web rule is `no-generated-look`; this one is for a plugin panel.

<constraints>
Always do:
- Use the standard metaphor for what has one (power, bypass, link, settings, undo, play) and say what it does in a label or tooltip.
- Draw every icon in one stroke weight.
- Show an icon dim at rest and in the accent colour when active.

Never do:
- Invent a glyph for something that already has a standard one.
</constraints>
