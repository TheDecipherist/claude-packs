# Each functional block is a column, named at its foot

A column name is the biggest text on the plate, so a user finds a block by its name before its controls.

<constraints>
Always do:
- Give each functional block a column, named at its foot in large bold uppercase: the biggest text on the plate.

Never do:
- Name a column in small or mixed-case type, or above its controls.
</constraints>
