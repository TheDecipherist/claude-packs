# A value is bound, never written into the SQL text

<constraints>
Always do:
- Pass every value as a parameter: `$1`, `%s`, or the driver's tagged form (`` sql`...` ``, `$queryRaw`).
- Take a table or column name from an allow-list in the code, and quote it with the driver's identifier helper.
- Connect read-only work as a database role that can only read. A wrapper that promises read-only is no boundary.

Never do:
- Build SQL from a value with a template string, an f-string, `%`, `.format`, `Sprintf` or `format!`.
- Trust a value because it came from your own database or a form with validation.
</constraints>

## Check
`pg-bind-values`. A line that is right anyway says so: `// pg: allow <reason>`.
