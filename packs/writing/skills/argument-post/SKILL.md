# The argument post: what the 750k-view post did

r/ClaudeAI, 935 pts, 165 comments.

"Why are all the Claude Code skill files I see online completely
pointless?" Two narrative posts by the same author in the same month did 13 and 8 points.
The difference is the whole lesson:

- **About the reader, not the author.** Everyone has a skill file; the
  first three lines make every reader feel caught. An argument the reader
  can test against their own setup in two seconds travels; a story about
  what the author did gets read by people who care about the author.
- **Shape:** one recognizable example everyone has seen (the quoted
  boilerplate) -> one-line verdict -> one principle ("the point of a skill
  is to fix something Claude consistently gets wrong") -> a short list of
  specific things it gets wrong -> restatement -> a humble ask ("Am I
  missing something?"). About 150 words. No numbers, no links, no
  product, no disclosure needed.
- **The list is the engine.** Four concrete one-liners from the author's domain;
  every reader has a fifth, which is where the comments come from.
- **The close lets people disagree without a fight,** so the argument
  fills on both sides.
- **Title = an opinion inside a question, about the reader's files.**
