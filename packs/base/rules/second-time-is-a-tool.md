# The second time a step is done by hand, make it a tool or a skill before going on

The same triage was written by hand on eight machines in one day. A step done twice is done a third time.

<constraints>
Always do:
- At the second hand-done run of a research or build step, stop and make it a script (when it is mechanical) or a skill (when it takes judgement), then use that.
- Put the script or skill where the project keeps such things, with its test or its pressure test.

Never do:
- Do a step by hand a third time.
- Write a skill for what a script does exactly, or a script for what takes judgement.
</constraints>
